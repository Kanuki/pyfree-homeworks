## Помощник-скачиватель документов (code/doc_downloader_hw6.py)

Ищет документ в интернете по названию и скачивает файл, чьё имя совпадает
с запросом — точно или частично.

### Установка

```bash
pip install playwright
playwright install chromium
```

### Использование

```bash
# частичное совпадение имени файла (по умолчанию)
python code/doc_downloader_hw6.py "отчет по продажам"

# только точное совпадение имени файла (без учёта расширения)
python code/doc_downloader_hw6.py "отчет по продажам" --exact

# куда сохранять (по умолчанию ./downloads)
python code/doc_downloader_hw6.py "отчет по продажам" --dir ./загрузки
```

Скрипт открывает headless-браузер, ищет запрос в DuckDuckGo, отбирает
среди результатов ссылки на документы (pdf, doc/docx, ppt/pptx, xls/xlsx,
txt, rtf, odt/ods/odp, csv, zip, rar) и скачивает первый файл, чьё имя
подошло под критерий. Если совпадений нет — сообщает об этом и ничего не
скачивает.
