## Помощник-скачиватель документов (code/doc_downloader_hw6.py)

Ищет документ в интернете по названию и скачивает файл, чьё имя совпадает
с запросом — точно или частично.

### Установка

```bash
pip install playwright
playwright install chromium
```

### Использование

```bash
# частичное совпадение имени файла (по умолчанию)
python code/doc_downloader_hw6.py "отчет по продажам"

# только точное совпадение имени файла (без учёта расширения)
python code/doc_downloader_hw6.py "отчет по продажам" --exact

# куда сохранять (по умолчанию ./downloads)
python code/doc_downloader_hw6.py "отчет по продажам" --dir ./загрузки

# без видимого окна, в фоне
python code/doc_downloader_hw6.py "отчет по продажам" --headless
```

По умолчанию скрипт открывает настоящее окно Chromium, и видно, как он
ищет запрос в DuckDuckGo. Среди результатов отбираются ссылки на документы
(pdf, doc/docx, ppt/pptx, xls/xlsx, txt, rtf, odt/ods/odp, csv, zip, rar),
и скачивается первый файл, чьё имя подошло под критерий. Если совпадений
нет — сообщает об этом и ничего не скачивает. Флаг `--headless` убирает
окно и запускает поиск в фоне.

**Важно:** видимое окно браузера требует графического окружения на
машине, где запускается скрипт (обычный компьютер с экраном). На сервере
без графики или в headless-контейнере используйте флаг `--headless`.

## Веб-интерфейс (code/doc_downloader_web.py)

То же самое, но без терминала: страница в браузере с полем ввода и
кнопкой «Скачать» — вместо того, чтобы каждый раз набирать команду.

### Установка

```bash
pip install playwright flask
playwright install chromium
```

### Запуск

```bash
python code/doc_downloader_web.py
```

Открыть в браузере: http://127.0.0.1:5000 — ввести название документа,
нажать «Скачать». Поиск идёт в фоне (headless), результат и путь к
скачанному файлу появляются прямо на странице.
